# ABEARCO Inc — abearco.org

Next.js site, hosted on Vercel. Migrated from Abacus AI (Nov 2026).

## Environment variables (Vercel → Settings → Environment Variables)
- `RESEND_API_KEY` — required for the contact form
- `CONTACT_TO_EMAIL` — optional, comma-separated recipients (default: Mike@abearcodevelopment.com)
- `CONTACT_FROM_EMAIL` — optional verified sender, e.g. `ABEARCO Website <website@abearco.org>`

## Local
npm install && npm run dev
